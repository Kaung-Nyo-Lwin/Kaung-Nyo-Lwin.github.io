## Kaung Nyo Lwin · Career Profile Site

This repository now powers a multi-page career profile that mirrors the structure of my résumé.

### Local development

1. Open the repository folder.
2. Launch a static server (for example `python -m http.server 8000`) and visit [http://localhost:8000](http://localhost:8000).
3. Navigate through the links (Home, Experience, Projects, Skills, Education, Contact) to view each section.

### Content overview

- `index.html` – Landing page with summary, highlights, and quick links to the rest of the site.
- `experience.html` – Detailed professional history.
- `projects.html` – Selected AI/ML and analytics projects.
- `skills.html` – Technical, analytical, and business skill groups.
- `education.html` – Academic background, certifications, and languages.
- `contact.html` – Contact information and references.
- `styles.css` – Shared styling for every page.
- `KaungNyoLwin_Resume_20102025.pdf` – Latest résumé referenced throughout the site.
