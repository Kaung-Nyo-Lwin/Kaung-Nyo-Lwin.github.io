L2BC · LEARN TO BE COOL

Teaching small models
with verifiable rewards.

A reinforcement learning framework that turns questions and tables into executable visualization code—and checks what the chart actually says.

Completed master’s thesisAsian Institute of TechnologyReinforcement learning · Generative AI

The problem

A chart can render successfully and still show the wrong data. Generating a useful visualization requires a language model to select and join tables, transform values, choose the right visual encoding, and produce executable code.

L2BC studies whether compact language models can learn that process from rewards based on checks of the program and its output. The goal is a model that internalizes the workflow and produces a complete program in one generation.

FROM A REQUEST TO VERIFIED FEEDBACK

01 / GENERATE

Question + data

A compact Qwen model generates candidate visualization programs from a structured workflow.

02 / EXECUTE

Run the program

The program executes, renders a chart, and exposes an output that can be checked.

03 / VERIFY

Inspect the result

Rules reconstruct the chart’s type and encoded data, then compare them with the ground-truth specification.

04 / LEARN

Update the model

GRPO and LoRA use the reward to update the policy. Verified performance also adapts the training controls.

This loop happens during training. The learned policy produces the visualization program in a single generation at inference.

What I developed

  • Rewards grounded in executable checks. Chart verification checks execution, chart type, and encoded data against a specification. Separate code checks evaluate adherence to the structured workflow.
  • Adaptive reinforcement fine-tuning. A custom TRL/GRPO trainer with LoRA uses a verified performance signal, called comfortability, to control sampling temperature, learning rate, and reward scaling.
  • Experiments that explain the result. Component ablations and analysis of seen and unseen tasks examine what the model learns, how model capacity changes the result, and where verification leaves gaps.

What the work showed

The best compact-model configurations matched or exceeded larger agentic visualization baselines on VisEval, using limited training data and one generation at inference. This showed that rule-based rewards can teach useful visualization behavior without a learned reward model or an LLM judge in the training loop.

The adaptive controls were more useful at the smaller model scale; their benefit was inconclusive for the larger model. The research also made failures easier to diagnose: named checks reveal execution errors, incorrect data, and aspects the reward never taught.

The central lesson: reliable feedback depends on what can be verified. A model can learn the checks it receives and still miss requirements outside that specification.

Research perspective

This is a completed thesis in Data Science and Artificial Intelligence at AIT. It brings together reinforcement learning, efficient LLM fine-tuning, program execution, chart parsing, and empirical model evaluation.

The experiments cover one benchmark and one model family. The work establishes a reproducible approach to verified correctness; aesthetic quality remains a separate evaluation question, and a missing rule can leave a blind spot.
